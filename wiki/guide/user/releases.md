# 版本更新记录

本页概览 HyperShell 的主要版本更新。完整变更清单请查看[仓库中的 CHANGELOG.md](https://github.com/watersupis/HyperShell/blob/main/CHANGELOG.md)；应用安装包和外置插件包请前往 [GitHub Releases](https://github.com/watersupis/HyperShell/releases) 下载。

## v0.3.2 - 2026-11-18

- 完善插件化架构，统一内置与外置插件的生命周期、权限和 UI 插槽。
- 增加主机监控、进程与端口管理、广播快捷指令等外置插件。
- 改进多会话工作区、会话录制、文本日志、标签页和连接管理。
- 发布中英文用户与开发者 Wiki，并增加三平台构建、插件打包和 Wiki 部署工作流。
- 修复标签页溢出后无法方便切换的问题。

## v0.3.1 - 2026-08-11

- 增加标签颜色和每个标签单独设置的终端字号。
- 修复本地终端调整大小后的残留显示、SSH 首条命令处理及 SFTP 路径安全问题。

## v0.3.0 - 2026-08-07

- 增加本地 shell 会话和配置文件，支持检测本机 shell 与 WSL。
- 增加动态标签标题、运行中进程名称显示和 WebGL 终端渲染。
- 增加 Electron 端到端测试，覆盖真实 preload、IPC、数据库和会话流程。

## v0.2.6 - 2026-06-06

- 增加应用外观主题，可选择深色、浅色主题或跟随系统。
- 调整更新提示和更新操作在侧边栏中的呈现方式。

## v0.2.0 - 2026-05-27

- 增加基于 GitHub Releases 的应用内更新检查与更新流程。
- 增加设置中的更新状态和手动检查入口。

## v0.1.0 - 2026-04-06

- 首个版本，提供 SSH 与串口终端、标签页和分屏、会话记录、主机管理以及双窗格 SFTP 文件管理。
