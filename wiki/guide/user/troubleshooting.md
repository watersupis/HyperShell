# 故障排查

## 功能入口不见了

打开“设置 > 插件”，确认目标内置插件已启用并按提示重启。外置插件需要安装有效 `.hspkg` 并授予所需权限；可安装不代表插件功能已经实现。

## SSH 连接停在连接中

先确认地址、端口、用户名和认证方式；再从系统终端使用 `ssh -v user@host` 检查网络、SSH 配置和 ProxyJump。首次连接应核验主机指纹。不要在公开日志中粘贴口令、私钥或完整凭据。

若系统 `ssh` 可连接而 HyperShell 不行，对比保存主机的认证方式、身份文件和目标参数，并检查应用实际构建版本。使用 SSH agent 时确认 agent 正在运行且已加载所需密钥。

## 主机指纹发生变化

指纹变化可能由服务器重装、主机密钥轮换或连接目标错误导致，也可能表示存在中间人风险。先通过独立可信渠道向服务器管理员核对新指纹；未核实前不要确认替换，也不要在不同端口/主机之间复用信任记录。

## SFTP 文件列表为空或本地目录无法加载

确认 SFTP 插件已启用，目标 SSH 会话正常。若本地 home/磁盘列表报 `No handler registered for 'fs:get-home'` 或 `fs:get-drives`，通常是当前运行的主进程未注册本地文件 IPC。完整退出并重启刚构建的应用，确认不是旧 `dist` 产物；仍失败时收集启动日志和构建版本。若目录可见但任务失败，查看传输队列的具体错误和目标路径，先确认远端目录权限、剩余空间及网络状态。

## Electron 报原生模块 ABI 错误

为当前 Electron 运行时重建原生依赖：

```powershell
pnpm --filter @hypershell/desktop rebuild:native
```

运行 Electron E2E 后，如果普通 Node 测试无法加载 SQLite 原生模块，再按 Node 测试运行时重建。区分 ABI 加载错误与应用测试断言失败。

## 插件视图空白

确认包版本、权限授权、插件 API 兼容性和实际实现状态。修改源代码不会自动更新已安装 `.hspkg`；重新打包、安装/更新并在提示时重启。排查时查看应用日志，但先清除任何密钥和敏感主机信息再分享。
