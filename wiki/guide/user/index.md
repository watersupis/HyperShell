# 用户指南

HyperShell 是以 SSH 为核心的桌面终端工作台。你可以管理主机和会话，并按需启用 SFTP、本地终端、串口、录制、隧道及外置插件。

## 开始使用

- [首次连接与文件传输](./first-connection)：添加主机、核验主机指纹、打开终端和 SFTP。
- [本地终端与串口](./local-and-serial)：配置本地 shell 与串口会话。
- [设置与数据](./settings)：了解终端选项、录制、空闲断开与数据备份。
- [功能与插件目录](./features)：了解功能用途、启用方式及当前限制。

## 常见任务

1. 使用快速连接连接临时 SSH 目标，或保存主机供后续使用。
2. 从主机列表双击主机打开终端；单击用于选中。
3. 在“设置 > 插件”启用可选内置插件，按提示重启。
4. 安装外置 `.hspkg` 前检查来源和权限，只授予实际需要的能力。

具体界面可能随版本变化。遇到功能缺失，先检查插件是否已安装/启用，并查看功能目录中的状态和限制。
