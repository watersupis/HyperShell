# 功能与插件目录

HyperShell 以插件组织功能。插件可选状态、具体入口和权限可能随版本变化；本页是使用入口。实际可用性请同时核对应用“设置 > 插件”中的状态，以及对应插件包的 manifest 和权限说明。

| 功能 | 说明 | 启用/打开 |
| --- | --- | --- |
| SSH 主机与终端 | 主机管理、SSH 会话、标签和工作区 | 核心功能，默认可用 |
| SFTP | 双窗格文件浏览、传输、同步、书签和远程编辑 | 在“设置 > 插件”启用并重启 |
| 本地终端 | 本地 shell、WSL 和本地配置文件 | 启用内置插件并重启 |
| 串口 | 串口配置和终端连接 | 启用内置插件并重启，需兼容设备 |
| 会话录制 | 终端工具栏可手动录制；录制库可浏览、回放和管理文件 | 自动录制和保存目录在终端设置中配置；录制库由核心内置功能提供 |
| SSH 隧道 | 本地、远程和动态端口转发 | 启用内置插件并重启 |
| 快捷指令中心 | 公共指令库、个人快捷指令、命令提示和终端输入广播 | 在设置的插件管理区启用内置插件并按提示重启 |
| Host Monitor | 在单独页面监控多个已连接 SSH 主机；终端工具栏入口聚焦当前主机 | 安装外置插件并授权监控读取 |
| Remote Process Manager | 在工作区页签查看当前 SSH 主机的进程、端口和 Docker 对象并执行受控操作 | 安装外置插件并授权所需操作 |
| Network Diagnostics | 目前只有插件骨架，不能当作可用诊断工具 | 尚未实现 |

快捷指令中心随应用提供，不需要安装外置包。其他外置插件通过 manifest 申请权限；安装不代表功能已经实现，获批权限也只限清单声明范围。安装前审阅来源、功能和权限。
