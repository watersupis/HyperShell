# 首次连接与文件传输

本教程假设你已安装 HyperShell，并持有目标 SSH 主机的授权信息。

## 添加并连接主机

1. 在主机列表中新建主机，填写名称、地址、端口和用户名。
2. 选择密码或私钥认证。私钥保留在本地，不要粘贴到备注或插件配置。
3. 保存后回到主机列表，双击主机连接。快速连接可使用 `Ctrl+K` 连接不保存的目标。
4. 首次连接时核验服务器主机指纹。使用可信的独立渠道与服务器管理员确认指纹；若已保存的指纹发生变化，先停止连接并查明原因，不要直接替换旧指纹。

认证失败时，先核对目标地址、端口、用户名和所选认证方式。使用私钥时确认对应公钥已配置在服务器上；如使用 SSH 配置或 agent，检查系统 OpenSSH 是否能连接同一目标。避免反复尝试或把口令、私钥内容复制到日志中。

## 使用终端工作区

成功连接后，中央区域会出现 SSH 终端标签。标签用于切换会话；分屏改变显示布局，不会把不同窗格变为同一会话。输入命令前确认当前活动标签和目标主机。

## 打开 SFTP

1. 打开“设置 > 插件”，启用内置 SFTP 插件并按提示重启。
2. 在主机列表选中目标主机，使用文件入口或主机右键菜单打开 SFTP。
3. 本地和远程窗格分别显示本地目录和远程目录。双击文件夹进入目录。

## 传输文件

- 从本地窗格拖至远程窗格：上传；反方向拖动：下载。
- 同一窗格内拖放到另一个文件夹：移动。
- 跨窗格拖放是上传/下载，不是跨端剪切。
- 窗格顶部的路径、返回上级和刷新控件用于定位和重新读取目录；复制/粘贴用于当前窗格内的文件操作。
- 传输前核对目标路径和文件名；同名冲突时按需要选择覆盖、跳过或重命名。
- 在传输队列确认任务状态和失败信息；大文件或网络不稳定时不要仅凭对话框关闭判断任务已完成。
- 远程删除不可逆时应格外谨慎；重要资料应有独立备份。恢复应用备份前确认目标应用版本和数据范围。

## 书签、同步与操作记录

SFTP 底部面板包含书签、操作日志、同步和传输队列视图。可将常用远程路径保存为书签，之后从书签列表快速返回。操作日志显示已执行的文件操作；对具备撤销数据的成功上传、下载、移动或重命名，日志行会提供撤销入口。撤销能力不是通用版本控制，重要文件仍需单独备份。

同步任务可选择本地到远程、远程到本地或双向，并填写两端目录和可选的逗号分隔排除模式。启动前逐项核对方向和路径；双向同步会作用于两端，不能把它当作只上传。当前同步不会自动删除孤儿文件。观察同步进度，结束后确认完成或错误状态。

## 编辑远程文件

可从远程文件列表打开文件进行编辑。二进制文件会以只读方式打开，避免文本转换损坏内容；需要修改时应使用合适的本地工具并通过文件传输更新。若服务器上的文本文件在打开后又被修改，保存时会提示选择覆盖服务器版本、重新载入、另存为或取消。重新载入会丢弃本地未保存更改；覆盖前确认没有需要保留的他人修改。

若本地 home 或磁盘列表无法加载，或远程主机密钥变化，参见[故障排查](./troubleshooting)。
