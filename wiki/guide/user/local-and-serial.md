# 本地终端与串口

本地终端和串口是可选内置插件，可在“设置 > 插件”启用；启停变更按界面提示重启。已连接到设备或 shell 后，终端标签与 SSH 会话一样受工作区布局管理。

## 本地终端

启用 Local Terminal 后，侧栏会列出可用 shell 配置。Windows 可检测 Windows PowerShell、PowerShell、命令提示符、Git Bash 和 WSL 发行版；其他平台会尝试系统默认 shell。双击可用配置打开会话。若安装了新 WSL 发行版或 shell，可使用侧栏重新扫描。

新增或编辑配置时，可设置显示名称、可执行文件、参数、启动目录、图标/颜色和环境变量。自定义环境变量会传给该配置启动的 shell；谨慎修改 `PATH`、`HOME`、`USERPROFILE` 等变量。检测到的配置重新扫描时会保留用户编辑；隐藏的检测项可从侧栏显示隐藏项后恢复。若可执行文件不可用，配置会显示为不可用，先修复路径或安装对应 shell。

## 串口终端

启用 Serial 后，可在侧栏新增串口配置。选择设备端口并按设备文档设置波特率、数据位、停止位、校验位和流控；两端参数必须一致，否则输出可能乱码或无法通信。端口列表可刷新。只有设备确实需要时才开启本地回显，避免字符重复显示；DTR/RTS 用于需要这些控制线的设备，不确定时先保持设备要求的默认状态。

保存配置后从侧栏打开会话。若端口未出现，确认设备已连接、操作系统驱动正常且未被其他程序占用；对 USB 转串口设备，也要确认选中的端口对应目标硬件。
