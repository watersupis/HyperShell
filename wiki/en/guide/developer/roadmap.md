# Requirements and Plan Status

The repository contains a FinalShell comparison document marked **pending review**. It is not an approved roadmap. Some proposed items have since been implemented: command snippets/broadcast, host monitoring, and process management. Network Diagnostics remains a skeleton. The old P1-P7 sequence must not be presented as a current commitment.

## Historical proposals

| Topic | Current documentation status |
| --- | --- |
| Quick commands and input broadcast | Quick Command Center is provided as a built-in plugin; future improvements need review to avoid duplicating its command library, suggestions, and broadcast |
| Multi-host monitoring | Host Monitor exists; historical trend/retention ideas need separate verification |
| Terminal and SFTP integration | Candidate feature; define path synchronization and shell-integration boundaries first |
| Network diagnostics | Current plugin entry is still a skeleton; not delivered |
| Transfer extensions/Zmodem | Historical technical exploration, not approved work |
| Remote process management | Process Manager already has process, port, and Docker views; additions require incremental review |
| RDP integration | Historical evaluation item, not an implementation commitment |

## Current roadmap source

The repository does not currently identify an authoritative product roadmap with owners, status, and acceptance criteria. Use confirmed issues/requirements as the source of active work. Before development, record the user goal, scope, risks, acceptance criteria, and cancellation conditions. Once a roadmap source is approved, list active items here with a verification date. Completed plans belong in the archive, not in the backlog.

Completed designs and implementation plans are not part of the current roadmap; useful constraints are summarized in [decision history](./decision-history).
