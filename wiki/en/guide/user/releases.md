# Release Notes

This page highlights major HyperShell releases. See the full [CHANGELOG.md](https://github.com/watersupis/HyperShell/blob/main/CHANGELOG.md) for the complete change history, and visit [GitHub Releases](https://github.com/watersupis/HyperShell/releases) to download application and external plugin packages.

## v0.3.2 - 2026-11-18

- Expanded the plugin architecture with shared lifecycle, permission, and UI-slot mechanisms for built-in and external plugins.
- Added external plugins for host monitoring, process and port management, and broadcast snippets.
- Improved multi-session workspaces, session recording, text logging, tab handling, and connection management.
- Published bilingual user and developer Wikis and added workflows for cross-platform builds, plugin packages, and Wiki deployment.
- Fixed tab navigation when the tab strip overflows.

## v0.3.1 - 2026-08-11

- Added tab title colors and per-tab terminal font sizes.
- Fixed stale local-terminal output after resizing, first-command handling in SSH shell integration, and SFTP path validation.

## v0.3.0 - 2026-08-07

- Added local shell sessions and profiles, including detected shells and WSL distributions.
- Added dynamic tab titles, active-process names, and WebGL terminal rendering.
- Added Electron end-to-end coverage for the real preload bridge, IPC, database, and session lifecycle.

## v0.2.6 - 2026-06-06

- Added application appearance themes, including dark, light, and follow-system options.
- Updated how application update notifications and actions appear in the sidebar.

## v0.2.0 - 2026-05-27

- Added update checks and in-app update flows through GitHub Releases.
- Added update status and a manual check action in Settings.

## v0.1.0 - 2026-04-06

- First release with SSH and serial terminals, tabs and split panes, session logging, host management, and dual-pane SFTP file management.
