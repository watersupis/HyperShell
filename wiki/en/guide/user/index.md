# User Guide

HyperShell is a desktop terminal workbench centered on SSH. Manage hosts and sessions, then enable optional features such as SFTP, local terminals, serial connections, recording, tunnels, and external plugins.

## Start here

- [First connection and file transfer](./first-connection): add a host, verify its fingerprint, open a terminal, and use SFTP.
- [Local terminal and serial](./local-and-serial): configure local shell and serial sessions.
- [Settings and data](./settings): review terminal options, recording, idle disconnect, and backups.
- [Features and plugins](./features): review available features, how to open them, and known limitations.

## Common tasks

1. Use Quick Connect for a one-time SSH target, or save a host for later.
2. Double-click a host to open a terminal; a single click selects it.
3. Enable optional built-in plugins in **Settings > Plugins** and restart when requested.
4. Review the publisher and requested permissions before installing an external `.hspkg` package.

The UI may change between releases. Check plugin status and limitations if an entry is unavailable.
